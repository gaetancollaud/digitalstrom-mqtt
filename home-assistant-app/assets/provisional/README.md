# Provisional Home Assistant App artwork

These files are design proposals supplied by Boris Moor on 2026-08-09:

- `icon-provisional.png`: square App icon proposal, 1254 x 1254 pixels
- `logo-provisional.png`: wide App logo proposal, 1983 x 793 pixels

They are intentionally not named `icon.png` or `logo.png`, so Home Assistant
does not treat them as active App artwork. They are retained as design history.

The refined final assets are stored in the App root:

- `../../icon.png`: 128 x 128 pixels
- `../../logo.png`: 250 x 100 pixels

Both final files use the reserved Home Assistant filenames and are validated by
CI.
